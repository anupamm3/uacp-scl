# Design Decisions

| ID  | Decision |
|-----|----------|
| D-1 | `<variable>` gets a required `name` attribute. `source` is a dotted path into runtime data. The body is an optional template wrapping `{{name}}`. |
| D-2 | A document has an implicit root. An optional `<scl version="1">…</scl>` wrapper is allowed. Mismatched tags raise a clear error with line and column. The blueprint's stray `</excel>` is a typo. |
| D-3 | MCP is a tool protocol, not a provider API. It is out of scope; it can be a future extension. |
| D-4 | Model IDs live only in `config/models.yaml` and environment variables, never in code. |
| D-5 | The UACP message from the blueprint is wrapped in a JSON-RPC 2.0 envelope as `params`. |
| D-6 | Generated code from Agent Beta runs only inside a sandbox (restricted subprocess with timeout). |
| D-7 | Contradiction resolution uses a documented scoring formula (Step 20) with tunable weights. |
| D-8 | Only free providers are used by default. The OpenAI-compatible adapter makes paid providers a config change. |
| D-9 | Whiteboard defaults to in-memory with an SQLite option. Redis is an optional backend. |
| D-10 | In the SCL `Output` AST node, `schema` is defined as `dict[str, Any] | None = None` with the Pydantic attribute shadowing warning suppressed, preserving direct property access (`output.schema`) over Pydantic's deprecated class method. |
| D-11 | SCL parser uses a dedicated raw-text scanning mode for `<output format="json_schema">` to permit unescaped JSON containing `<` and `>` up to the closing `</output>`. AST nodes support optional `store_spans` (default `False`), allowing clean round-trip equality `parse(format(parse(x))) == parse(x)`. |
| D-12 | SCL variable binding escapes `<` to `&lt;` and `>` to `&gt;` in runtime values to prevent prompt/XML injection breakouts, preserving valid JSON payloads while protecting AST structure. Dotted-path resolution raises `MissingVariableError` with fuzzy match candidates. |
| D-13 | Output schema normalization uses table-driven keyword stripping and transformation for `openai_strict` (adds `additionalProperties: false`, forces all properties into `required`, turns optional fields into nullable `anyOf` unions) and `gemini` (strips unsupported OpenAPI keywords) with verified idempotence. Output enforcement uses `Draft7Validator` and `invoke_with_repair` auto-appends validation errors for multi-turn repair attempts. |
| D-14 | Adapter foundation replaces the minimal enforcer protocol with the full `Adapter` ABC, `CompiledRequest`, and `LLMResult` models. `LLMResult` synchronizes `text` and `content` for complete backward compatibility. Sliding-window `QuotaGuard` tracks per-minute and daily requests from `config/models.yaml` with environment variable overrides and supports both sleep and raise modes. |
| D-15 | `GeminiAdapter` integrates the official `google-genai` SDK using `client.aio.models.generate_content`. API key is loaded strictly from `GEMINI_API_KEY` (never logged or printed). Compilation structures identity into `system_instruction`, SCL examples into alternating `user`/`assistant` (`model`) turns, data blocks and query into the final user turn, and normalizes `strict=True` JSON schemas with fallback to `json_mode`. Invocation wraps calls in `QuotaGuard`, `with_retry`, and timeouts, mapping SDK exceptions (`ClientError`/`APIError` 429 to `RateLimited`, 401/403 to `AuthError`, `MAX_TOKENS` to `TruncatedOutput`, safety blocks to `ModelRefusal`). |
| D-16 | `OpenAICompatAdapter` integrates the official `openai` SDK using `client.chat.completions.create` with configurable `base_url` and `api_key_env`, serving Groq, OpenRouter, and compatible endpoints. Environment loading is centralized in a shared `load_env()` helper in `registry.py` to avoid duplication. Configuration in `config/models.yaml` defines default provider settings and alias overrides. Compilation compiles identity into system message, examples into alternating user/assistant turns, data blocks and prompt into the final user turn, and dynamically selects output mode (`native_schema` with `openai_strict` normalization, `json_mode` with schema instructions, or `prompt_only`). Invocation is protected with `QuotaGuard`, timeouts, exponential backoff honoring `Retry-After`, and exception mapping (429 to `RateLimited`, 401/403 to `AuthError`, `finish_reason == "length"` to `TruncatedOutput`, content filters and refusals to `ModelRefusal`). |
